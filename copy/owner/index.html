हिशोब · Sharing it

For the person who shares हिशोब with other people. You set up one of these once, ideally on a computer. Everyone you share it with then needs no code at all.

The update list. Every shared script updates itself from your Config sheet. Each row is one edition: edition, version, url, sha256, notes, one value per cell. After every release, edit the existing row for that edition; don't add a second one. The version in a row must match the version inside the code it points to.

The shared Google Sheet

Set up once

People make a copy of this sheet, tap Expense Tracker › Start, and their cards are found automatically. The script inside is a small loader, so every copy keeps itself up to date. The Copy page's "Make your own copy" button points at this sheet.

Steps and code preview

Don’t paste this into your own alerts project. It goes only into the template sheet.

  1. Open Expense Tracker – Card Alerts in your Google Drive.
  2. Make sure the Config sheet has a sheet row with the current version and fingerprint. Without it the loader has nothing to download.
  3. Extensions › Apps Script, delete what's there, paste the sheet loader, and Save. Don't run anything, and never put your own Notion key in this template.
  4. Check the Script Properties (Project Settings) are empty, then make a test copy from a second Google account, tap Expense Tracker › Start, and check it asks for a Notion key and starts cleanly.
  5. Share › General access › Anyone with the link (Viewer).

The setup link

Set up once

One link that sets up everything on someone's phone: their Notion tables, card alerts, the dashboard as a file for Scriptable, and the shortcut, Back Tap and widget steps. Works on a phone, so it suits people who can't use the sheet.

Steps and code preview
  1. Go to script.google.com › New project. Rename it Expense Tracker (people see this name when they sign in).
  2. Delete what's in Code.gs and paste the setup-link loader. Near the top, paste your Log Expense shortcut's iCloud link between the quotes on the SHORTCUT_LINK line (in Shortcuts: ••• on the shortcut › Share › Copy iCloud Link). Save.
  3. Files › + › HTML, name it dashboard, delete what's in it, and paste the dashboard code from the Copy page. Save. Don't run anything.
  4. Deploy › New deployment › gear › Web app. Execute as: User accessing the web app. Who has access: Anyone with Google account. Deploy, and allow access when Google asks.
  5. Copy the Web app URL (it ends in /exec). That's the setup link you send out.

Updating later: the loader updates its own code. When a new dashboard comes out, paste it into the dashboard file, then Deploy › Manage deployments › pencil › Version: New version › Deploy. The link stays the same; people get the new dashboard by tapping Get the dashboard on the link again.

Google shows people a "hasn't verified this app" screen the first time (Advanced › Go to Expense Tracker). Unverified scripts like this work for up to 100 people.
