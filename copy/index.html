Card alerts sync (Google)

For me

Every 10 minutes it adds new bank and card alerts to Notion, matches them to what you logged and tags the card. Paste this small loader once; after that it keeps itself up to date.

Steps and code preview
  1. In Notion, open CC Transactions (Beta) › ••• › Connections and add the same integration your Expenses table uses.
  2. Open script.google.com (easiest on a computer; on a phone use Safari's "Request Desktop Website"), signed in to the Google account whose email you want read. Tap New project, delete what's there, and paste the loader.
  3. Paste your Notion key (starts with ntn_) between the quotes on the NOTION_TOKEN line near the top. Save.
  4. Choose the function install in the toolbar and tap Run. Allow Gmail access when Google asks. It then runs every 10 minutes by itself.
  5. Clear the key from the NOTION_TOKEN line (leave the quotes) and Save. It's already stored privately.
  6. Already set up the old way? Paste the loader over the old code in the same project and Save. Your key, cards and timer are kept; you don't need to run install again.

Two switches at the top of the loader: AUTO_UPDATE (false stops all update checks) and COUNT_ME (false stops the anonymous once-a-day visit count). Your SMS-to-email automation stays as it is.

Share with a friend

For friends

Two ways, both set up once by you. Friends then need no code at all. Pick the one that suits them: the shared sheet works best on a computer, the setup link works on a phone.

Shared sheet (the template)

Set up once, on a computer

Friends make a copy of a Google Sheet, tap Expense Tracker › Start, and their cards are found automatically. The script inside is a small loader, so every copy keeps itself up to date.

Steps and code preview

Don’t paste this into your own sync project. It goes only into the Card Alerts sheet.

  1. Open Expense Tracker – Card Alerts in your Google Drive.
  2. Make sure the Config sheet has a sheet row (edition, version, url, fingerprint), like the alerts and link rows. Without it the loader has nothing to download.
  3. Extensions › Apps Script, delete what's there, paste the sheet loader, and Save. Don't run anything, and never put your own Notion key in this template.
  4. Make a test copy from a second Google account, tap Expense Tracker › Start, and check it asks for a Notion key (so yours didn't come along) and starts cleanly.
  5. Back in the sheet: Share › General access › Anyone with the link (Viewer). Friends use the sheet's Make a copy link.

Google shows friends a "hasn't verified this app" screen the first time (Advanced › Go to…). The Google Sheets phone app doesn't show the sheet's menu; on a phone use the setup link instead.

Setup link (works on a phone)

Set up once, on a computer

One link that sets up everything for a friend, on their phone: their Notion tables, card alerts, the dashboard as a file for Scriptable, and the shortcut, Back Tap and widget steps.

Steps and code preview
  1. Go to script.google.com › New project. Rename it Expense Tracker (friends see this name when they sign in).
  2. Delete what's in Code.gs and paste the setup-link loader. Near the top, paste your Log Expense shortcut's iCloud link between the quotes on the SHORTCUT_LINK line, if it's there (in Shortcuts: ••• on the shortcut › Share › Copy iCloud Link). Save.
  3. Files › + › HTML, name it dashboard, delete what's in it, and paste the dashboard code from the Dashboard section above. Save. Don't run anything.
  4. Deploy › New deployment › gear › Web app. Execute as: User accessing the web app. Who has access: Anyone with Google account. Deploy, and allow access when Google asks.
  5. Copy the Web app URL (it ends in /exec). That's the setup link to send friends.

Updating later: the loader updates its own code. When a new dashboard comes out, paste it into the dashboard file, then Deploy › Manage deployments › pencil › Version: New version › Deploy. The link stays the same. Friends get the new dashboard by tapping Get the dashboard on the link again.

Google shows friends a "hasn't verified this app" screen the first time (Advanced › Go to Expense Tracker). Unverified scripts like this work for up to 100 people.

Private edition

No Notion, no Google

A separate copy of the dashboard for someone who wants their data on their phone only. It reads credit card and bank statements (PDFs from net banking) and anything logged by hand. Update it from Settings › Updates, same as the main dashboard.

Steps and code preview
  1. Install Scriptable from the App Store.
  2. In Scriptable, tap +, rename the script Expenses Dashboard, paste the code, and tap ▶.
  3. To log by hand: use your Log Expense shortcut with Back Tap, or the dashboard's + Add expense.
  4. Each month: download the card and bank statements, then tap Import a statement and pick the PDFs. If a statement is password protected, it asks for the password. Spends already logged by hand are matched, not added twice.
  5. Settings › Your data: choose This iPhone only or iCloud Drive, and Export a backup now and then. If data is kept only on the phone, deleting Scriptable deletes it.

Card payments, refunds and incoming money aren't counted as spending. ATM withdrawals are left out (log cash spends by hand). Scanned (image) statements can't be read. Card alerts and Gmail features aren't in this edition.

What's new

New: the shared sheet updates itself too (10 Oct)

  • Friends: make a copy of the sheet, tap Expense Tracker › Start in its menu, paste a Notion key, and allow Gmail. No code to paste, and fixes arrive by themselves.
  • You: paste the new sheet loader (see "Shared sheet for friends" below) into the template once. Copies made from then on stay up to date; copies made earlier keep the old code until they are replaced.
  • The same two switches apply: AUTO_UPDATE and COUNT_ME. Phone users who can't see the sheet's menu can use the setup link instead.

New: a clearer top bar, month and year pickers, and custom splits (10 Oct)

  • The top bar now says "Money" and holds only the tabs. The month no longer sits above tabs that don't use it.
  • Overview: the month is just under the tabs. Tap the month name to jump to any month: pick a year, then a month. On a past month a This month button takes you straight back.
  • Trends: one year choice at the top (Calendar or FY, with arrows). Tap the year to pick any year from a list. The year summary, both charts and the average card all follow it, so going back a year is one tap.
  • Expenses: tap the selected month chip to open the same month picker.
  • Splitting an expense: Edit › Split / owed now has Full, 90%, 75%, 50%, 25% and an Other % box for each person, a plain amount box for any custom figure, and Split the other ₹X equally for whatever is left. Your share always shows as what remains.
  • Update from Settings › Updates, as before.

New: the Google scripts now update themselves (10 Oct)

  • Paste once, never again. The Card alerts sync and the Setup link code below is now a small loader. It downloads the real code, checks it against a fingerprint, keeps it in your Google account and runs it. New versions install themselves, and if a new version ever fails to start it goes back to the one that worked.
  • Already using the sync? Paste the new loader over the old code in the same project and Save. Your token, cards and 10-minute timer are kept, so you don't need to run install again. For the Setup link also do Deploy › Manage deployments › pencil › New version › Deploy once. If the loader asks for the Notion key, leave the line empty.
  • What it contacts: about once a day it reads the public update sheet. If COUNT_ME is true it also makes one anonymous visit count with no name, email or ID, so the author can see roughly how many people use it. Nothing else leaves your account beyond what the sync already did with your own Notion and Gmail.
  • Two switches at the top of the loader: change AUTO_UPDATE to false to stop all update checks (you keep the code you have), or COUNT_ME to false to switch off the visit count.
